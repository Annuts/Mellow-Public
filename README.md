## 为什么做小满

大多数「个人助理」要么把你的生活全存到别人的云端，要么只是一个聊完就忘的对话框。

小满想做的是另一件事：**数据先留在你自己的手机里，平时安安静静帮你记事、收资料、守着提醒；需要的时候，像一个记得你生活细节的老朋友，克制、有边界地搭把手。**

## 它能做什么

- **自然语言记事与准时提醒**
  说一句「十分钟后提醒我喝水」或「明晚七点打球，提前半小时叫我」，直接写入日程并登记系统精确闹钟。聊天里新建提醒、待办、清单和笔记可当场办好，**24 小时内可撤销**；改期、删除、控家居等操作必须先经你确认。
- **离线收集与随时找回**
  从任意应用把文字、链接、截图或 PDF 分享给小满。手机端**离线 OCR 识字**、**离线中文语音转写**，按关键词随时找回原文、原图和页码。
- **把零碎的生活收拢到一处**
  待办与惦记着的事、家庭库存与购物清单、菜谱、循环家务、账单与订阅、饮水与心情、人物与生日；授权后可只读查看手机日历、通讯录与 Health Connect。
- **满娘陪伴与人生档案**
  首页是会随昼夜和季节变化的小房间（支持「暖团」与「满娘」两套形象），可以喂食、摸摸、写日记、记感受，看周月回顾、给未来的自己写信，或导出不依赖小满的加密人生档案。
- **克制且透明的主动关怀**
  主动建议默认守安静时段（22:00–08:00）与每日额度（默认 3 条），刚聊过天会自动让位。打开「我的 → 小满在想的事」，能清楚看到她**为什么想起这件事、为什么决定说或没说**。

### 30 秒真实场景

> 把一张牙科预约截图从相册分享给小满 → 手机离线识别截图文字 → 你核对日期和时间后一键加入日程 → 到点在通知栏直接点「已办好」 → 以后想查诊所地址，在收集箱搜诊所名就能找回原图。
>
> **以上全程在手机本机完成，离线可用，不需要配置 AI 密钥。**

## 快速开始

### 1. 只用手机（推荐先体验）

1. **下载安装**
   前往 [Releases 页面](https://github.com/Annuts/Mellow-Public/releases) 下载最新的已签名 `Mellow-<构建号>.apk`（适用于 Android 8.0 及以上的 arm64 手机），在手机上直接安装。
2. **试用与权限**
   打开「聊天」，输入「十分钟后提醒我喝水」即可体验。为了让提醒准时送达，请按引导开启系统通知与「闹钟和提醒」权限（OPPO / 一加等国产系统后台设置见[准时提醒与精确闹钟权限](docs/使用指南.md#准时提醒与精确闹钟权限)）。
3. **按需配置 AI 模型（可选）**
   记事、提醒、离线 OCR、离线语音都**不需要**密钥。想使用自由聊天、自动记忆提炼或主动联想，可到「我的 → 高级 → 模型」填入你自己的 DeepSeek 密钥并开启「使用手机直连」。
4. **升级与换机**
   - **升级**：下载同签名的新版 APK 直接覆盖安装即可，**不要先卸载旧版**。
   - **换机**：在旧手机「我的 → 隐私与备份」导出加密备份并另存到手机以外，新手机安装后恢复即可。

### 2. 自托管家庭中枢（可选）

如果你有一台常开的电脑或 NAS（装有 Docker Compose 和 Python 3.11+），可以部署小满家庭中枢，解锁多设备同步、网页管理台、语义检索与家庭共享：

```sh
git clone https://github.com/Annuts/Mellow-Public.git Mellow && cd Mellow

# 1. 初始化加密资料库与自签 TLS 证书（以 macOS 路径为例）
python3 -m venv services/center/.venv
services/center/.venv/bin/python -m pip install -e services/center
MELLOW_DATA="$HOME/Library/Application Support/MellowCenter"
services/center/.venv/bin/mellow-center --data-dir "$MELLOW_DATA" init --hostname mellow-mini.local

# 2. 按部署文档生成密钥文件、创建外部数据卷并编写 production.env（见部署中枢第 2–4 步）

# 3. 启动中枢并生成手机配对邀请
docker compose --env-file production.env up -d --build --wait
docker compose --env-file production.env exec -it center python -m mellow_center \
  --data-dir /var/lib/mellow pair --name 我的手机 --space personal --admin \
  --lan https://mellow-mini.local:8765
```

把最后一条命令输出的配对邀请粘贴到手机「我的 → 连接 → 家里的小满主机」即可完成配对。
完整部署步骤、TLS 证书信任、Tailscale 异地访问、自动备份与升级方法，请阅读 **[家庭中枢部署指南](docs/部署中枢.md)**。

## 手机还是中枢？

| 使用需求 | 只用手机 | 接上家庭中枢 |
| --- | :---: | :---: |
| 记事、提醒、待办、离线 OCR、离线语音、日记与满娘 | ✅ | ✅ |
| 手机直连自己的模型自由聊天与提炼记忆 | ✅ | ✅ |
| 多设备自动同步、浏览器管理台、主机自动加密备份 | — | ✅ |
| 家庭共享清单与日程（不共享个人聊天与日记） | — | ✅ |
| 中文语义检索（换个说法也能找回旧资料） | 词法与近义词 | ✅ 混合语义检索 |
| 更连贯的主动联想（中枢主想、手机兜底） | 本机执行 | ✅ |
| 接入 Home Assistant、只读邮箱信头、行程/酒店查询 | — | ✅ |
| 亲友托付与继承核验 | — | ✅ |

## 隐私与数据安全

- **没有官方云端**：小满不设任何官方服务器，你的资料不经过作者或任何第三方中转。
- **默认本地加密**：手机端资料库整库 AES-256-GCM 加密；中枢端逐记录加密，密钥与证书不进 Git、不进 Docker 镜像。
- **授权彼此独立**：存在哪、是否同步、给不给模型看、能否用于主动联想、能否家庭共享，全部是独立开关。
- **记忆透明可控**：每条自动提炼的记忆都附带你的原话依据，随时可确认、修改、暂停或删除，删掉后不会复活。
- **模型直连透明**：只有填入你自己的模型密钥后才会调用模型，且仅发送当前问题与你允许的上下文；经纬度坐标永不发给模型。
- **证书公钥固定**：手机固定中枢自签证书的公钥指纹，证书到期自动续期时无需重新配对。

## 常见问题

<details>
<summary><strong>一定要填 AI 密钥吗？</strong></summary>

不用。记事、提醒、离线 OCR 识字、离线中文语音、生活记录以及常见时间提醒指令都完全离线可用。只有自由聊天、自动记忆提炼和模型主动联想需要填入你自己的 DeepSeek 密钥。
</details>

<details>
<summary><strong>我的数据会上传到哪里？</strong></summary>

不配对中枢时，数据只留在你的手机里。使用模型功能时，仅把当前问题和你授权的上下文发给你自己配置的模型服务商；配对中枢后，数据只同步到你自己部署的中枢主机。
</details>

<details>
<summary><strong>主动提醒会不会很吵？可以关吗？</strong></summary>

默认开启，但默认遵守安静时段（22:00–08:00）和每天 3 条的额度限制，刚聊过天也会自动让位（你自己明确设定的提醒不受额度影响）。在「我的 → 提醒与打扰」可以按类别或整体关闭，也可以随时对小满说「今天少打扰」。
</details>

<details>
<summary><strong>手机锁屏或清理后台后，提醒还会准时吗？</strong></summary>

你明确设定的提醒走 Android 系统精确闹钟，需要授予「闹钟和提醒」权限。主动念头会提前算好未来 24–36 小时的候选，到点仅在本机判断是否送达、不联网调模型。部分国产手机（如 ColorOS）需要手动放开耗电与自启动限制，详见[使用指南](docs/使用指南.md#准时提醒与精确闹钟权限)。
</details>

<details>
<summary><strong>支持 iPhone 吗？</strong></summary>

暂时不支持，目前仅提供 Android（arm64）安装包。
</details>

<details>
<summary><strong>换新手机怎么迁移数据？</strong></summary>

在旧手机「我的 → 隐私与备份」导出加密备份（单份上限 128 MB，不含支付通知账本与模型密钥），传到新手机恢复即可。已配对家庭中枢的手机也可以直接从中枢恢复同步数据。
</details>
