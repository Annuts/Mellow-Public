# 使用指南

小满是住在手机里的生活陪伴，有五个标签：**小满、聊天、生活、记忆、我的**。不连接任何电脑也能用。想跨设备接续，再连接自己的[小满中枢](部署中枢.md)。

## 第一次打开

只有一部 Android 手机时，拿到签名 APK 后就可以安装并直接进入小满。打开「聊天」，输入「十分钟后提醒我喝水」，跟着提示设好提醒，就能先试用一次。安装包来源和以后怎么升级见[快速开始](../README.md#快速开始)。

应用会引导你开启系统通知和准时提醒权限。不开也能记事，但提醒可能晚到或收不到。具体设置见[准时提醒与精确闹钟权限](#准时提醒与精确闹钟权限)。

要用模型聊天，到「我的 → 高级 → 模型」点「选择模型与填写密钥」，填入自己的 DeepSeek 密钥并开启「使用手机直连」。密钥保存在手机的安全存储里，对话问题和选中的上下文会发给模型服务商。只想记事、离线识字或设提醒，可以跳过这一步。各项功能的条件见[手机功能对照](../README.md#它能做什么)。

## 把一件事交给小满

- **说一次，再随口改。** 在普通聊天说“明晚七点打球，提前半小时叫我”。小满会写进日程并安排 18:30 的提醒。中间聊了别的话也可以说“打球改到八点”。当前对话只有一个符合条件的未来活动时，直接说“改到八点吧”也可以。有多场时小满会追问。
- **到时候想起以前交代的事。** 先说“下次去我妈家带充电器”，再说“周六去妈妈家吃饭”。小满会把“带充电器”作为相关候选，按主动开关和额度决定是否顺口提或留在首页，不再强行附在每次回复后。你也可以主动打开跟进清单，只有一件时直接选时间或点「办好了」。同一个地点、人或项目有好几件事时，点「勾选事项，一起设置提醒」，选好后只需挑一次时间。每件事都有独立的通知操作。你手动选定时间后，即使手机没有定位到目的地，到点也会提醒。
- **从分享的截图建日程。** 从 Android 分享菜单把订单、预约或门票交给小满。点「查看资料 → 从这份资料创建日程」，核对名称、日期、开始时间、地点和预留时长，再点「加入日程」。识别到多个日期或时间会留空供你选择，图片没有识别出文字也可以手填。日程卡可打开原资料。标记为仅本机的原资料所生成的日程也保存在本机。
- **到点就回答。** 展开 Android 事项通知，按内容可选「已出发」「已取件」「带好了」「买好了」或「已办好」，也可以选「10 分钟后」。取件和采购另有明天 18:00 再办的按钮。按钮会打开小满并保存选择。点通知正文进入该事项，错过时间后可选「明天 18:00」或「这次不用了」。晚间回顾还可打开今天最多三条待处理提醒。

**只在状态栏看到通知时**，进入「我的 → 提醒与打扰 → 让提醒更准时」，找到对应类别，点右侧「试发」。九类提醒各走自己的系统通知渠道，示例不会创建待办。点试发通知会回到检查页，点类别名称可以查看系统设置。已有渠道会沿用该手机之前的重要性设置。ColorOS 还需检查该类别的「横幅」或「悬浮通知」以及系统勿扰。解锁时横幅会显示手机上的事项正文。锁屏是否显示详情、收到通知是否亮屏由手机隐私和显示设置决定。仅有中枢后台到期信号、手机尚未同步到原文时，正文会先用通用提示。

希望小满在你看过 App 后仍提醒当天的重要事情，可以在「提醒与打扰」开启「有时效的事及时提醒」。这会同时启用念头仲裁。距最近访问和聊天至少半小时后，小满可主动提醒有时效的内容，继续遵守安静时段、已关闭的类别和每日额度。

## 五个标签

| 标签 | 做什么 |
| --- | --- |
| 小满 | 首页是满娘的小房间，不是仪表盘。要告诉你的事，都由她用对话气泡说出来，最多三条，详见[满娘的小房间](#满娘的小房间)。配对中枢后，检查到新版本时顶部会提示。 |
| 聊天 | 和小满说话，也是最快的记事方式。主聊天按时间显示消息，点顶栏头像或标题可以打开历史会话。「聊过的事」按事查看和续聊，长按你说的话可调整话题。也支持临时聊天和「只记下来」。 |
| 生活 | 按生活的角落分组。**今天**：安排、提醒、要做的小事、惦记着的事、到家了提醒我、手机日历。**吃饭与采购**：库存与食材、购物与准备清单、菜谱、今晚吃什么。**家里**：循环家务、家务与习惯、衣橱与搭配、家里的设备。**身体**：经期与健康手记、喝水和睡前提醒、运动与饮水、记一杯水、睡眠、步数与运动。**钱**：账单到期、订阅清单、账单。**人**：礼物与约定、久未联系提醒、家人与朋友、生日与纪念日。**心情与感受**：日记、每周回顾、心情与感受。**更多**（点开展开）：计划与项目、资料与附件、出门前的准备、手机联动、为你精选。 |
| 记忆 | 首屏有「我的小笔记」和「写一条」按钮，可读最近修改的一条。下面是关于我、人生档案、写给未来、与过去的我对话、收集箱几个入口，还能搜索、按层级筛选小笔记。有项目简介和进展时，列表里会出现「最近的项目」，点开看最近更新。右上角「更多」菜单有：导入 JSON、选择导出、聊天里记下的我、翻翻以前说过的话。 |
| 我的 | **满娘**（满娘与外观、语音）、**小满在想的事**、**提醒与打扰**、**今日运势与早安**、**连接**（家庭共享、托付与继承，这两项连接中枢后才有；同步、家里的小满主机、外部生活账户、连接其他应用）、**隐私与备份**（有同步冲突时多一项「待处理的同步」）、**关于**（检查更新、开源致谢）。**高级**默认收起，里面是模型、开发工具连接器、使用量、诊断。「小满在想的事」可看她为什么想起某件事、在等什么时机，见[主动建议](#主动建议)。 |

「生活」顶部有一张「接下来」卡片，先显示今天还要处理的日程、提醒或习惯。提醒和小事可以直接完成，日程和习惯点进去查看。「今天的安排」预览后续三项，点标题可查看全天。「身体」里的「记一杯水」记 250 ml，记错了可以撤销。有可采纳的建议时，列表底部会出现「小满想到的」。「手机日历」和「睡眠、步数与运动」只在 Android 上有，「为你精选」连接中枢后才有。

生活里的几行是同一种「循环事项」页：「循环家务」（每周）、「喝水和睡前提醒」（每天）、「账单到期」（单次）、「订阅清单」（每月）、「礼物与约定」（单次）、「久未联系提醒」（每隔几天）、「生日与纪念日」（每年）。选日期和重复方式，提醒只保存在这台手机上。「经期与健康手记」默认关闭，开启后只存在手机加密库里，不同步，不参与聊天和主动建议。

你的资料统一保存在一起，不再区分个人、生活、工作空间。家庭清单和日程从「家庭共享」进入，不会共享个人聊天、画像或日记。进入家庭共享后，底栏只剩「小满」和「我的」两个标签，「小满」是共享清单和日程的页面，没有满娘的小房间，也不涨经验。

## 满娘的小房间

「小满」标签是满娘的房间。房间会随时段和季节换样子：早晨、白天、傍晚、夜里各有各的光线，春夏秋冬的摆设也不同。深夜她会睡着。没事的时候她会自己动一动，做什么看心情、饱腹和精力。

**她说话。** 以前放在首页的内容，现在都是她说的气泡。气泡最多三条，按下面的顺序排，空了就说一句闲话。每隔一会儿自动换下一条，带按钮的不会自己换，点圆点可以手动切。

| 顺序 | 内容 |
| --- | --- |
| 1 | 「接下来」：最近的一件事。详情里最多再列两条「之后还有」，点开进对应页面 |
| 2 | 提问和跟进：小满想了解你的问题（回答或略过）；晚上有值得问的事时，一条带「先不了 / 说说」的感受询问 |
| 3 | 她自己的需要：饿了，或夜里困了。点一下就喂食或哄睡 |
| 4 | 小提示：吃饭、休息、天气，晚上变成「想聊聊今天吗」 |
| 5 | 今日运势，或填写生日和职业的邀请，可选「不再提示」 |
| 6 | 热点：一条未读的新闻摘要 |
| 7 | 闲话 |

每个气泡可以左右滑，也可以点圆点手动切。

**顶部。** 左边是头像，旁边是问候和日期。右边是日历（今天的安排）和铃铛（[消息](#消息没有收到通知也找得到)，带未读数）。下面一排小标签：「Lv n 称号」、心情、饱腹、精力三个小指示、天气（读你查过的那次结果，不会自动联网，点开是日程与天气）。今天记过心情才会出现一个带数量的小标签，点开是「心情与感受」。同步只在正在同步或出问题时显示一个小图标，正常时不显示。

**底部四个按钮。** 以下是默认的「暖团」样式。换成「满娘」样式后，喂食、摸摸、玩耍（或哄睡）改成屏幕左侧一列，底部只剩「和她说话」和语音按钮。

| 按钮 | 做什么 |
| --- | --- |
| 喂食 | 选小饼干、热牛奶或草莓蛋糕，每天有一样是她的最爱，吃到会更开心 |
| 摸摸 | 摸摸她 |
| 玩耍 | 陪她玩。每天 22:00 到次日 5:00，或她精力偏低时，换成「哄睡」 |
| 和她说话 | 轻点进聊天，长按或点右上角的麦克风进语音 |

**成长。** 点头像、等级标签或指示条，打开「成长」页：等级和经验条，心情、饱腹、精力、亲密四项状态，连续陪伴的天数，今天一起做的事，21 个可点播的小表情，还有每类事的经验规则。等级最高 99，前 15 级各有称号，从「初识」到「一生挚友」。

经验来自陪她，也来自过日子，每一类每天有上限，刷不出等级：

| 来源 | 经验 | 每天几次 |
| --- | --- | --- |
| 来看她（打开应用） | 10，再加连续陪伴的天数，最多加 7 | 1 |
| 喂食 | 6 | 3 |
| 摸摸 | 3 | 5 |
| 玩耍 | 4 | 4 |
| 哄睡 | 5 | 1 |
| 完成待办 | 8 | 8 |
| 完成提醒 | 6 | 8 |
| 记录心情 | 6 | 5 |
| 聊天 | 2 | 10 |
| 写日记 | 6 | 3 |

超过上限的互动不再加经验，但她的状态照样会变。

**不会惩罚你。** 几天没来，她的状态会慢慢降，但有下限，不会再往下掉。她不会生病，不会死，也不会走。你回来的那一刻，数值就按时间结算好了。

满娘的成长数据只存在手机上，不自动同步。手机加密备份会带上成长数据，恢复时整体保留进度更高的一份，不叠加经验和每日计数；新手机刚领过签到经验也能恢复之前的成长。

## 记一件事

在「聊天」或首页说一句话就行，例如「下次见小陈还书」「云盘每月 19 号扣款」「周六下午三点打网球」。

本人在本轮明确要求新建提醒、待办、清单项或笔记时，小满可直接保存；聊天原话下会留下「已执行」操作卡片。点卡片上的「撤销」可在执行后 **24 小时内**撤回；关掉聊天再打开仍能找到。如果事项已被你或其他设备修改，会提示撤销冲突，不覆盖后来的记录。超过 24 小时请在对应编辑页处理。同一次操作重复点按不会重复执行。没有配置模型时，常见日期和「半小时后」「一个半小时后」「一刻钟后」「两个小时后提醒我」也能离线识别；只说「十分钟后提醒我」时标题默认为「提醒」，之后可修改。

### 聊天里的确认卡片

**改期、取消或删除原事项、行程改出发日、控制家居设备、对外发送**不会因为模型的一句话就执行。小满先留下待确认卡片，列出对象与参数；你点「确认」后才提交。草稿 15 分钟后失效，来源、授权或目标版本有变化也必须重新核对。

- **修改**：改期可填写含时区的时间（如 `2031-06-12T19:30:00+08:00`）；函数草稿的其他参数可修改 JSON。改完仍需再点一次「确认」，不会边改边执行。旧式组合安排只支持整体调时间，其他修改请取消草稿后重新描述。
- **取消**：丢弃草稿，原事项不变。直接打开日程、提醒或行程的编辑页保存，仍按你在页面上的明确操作处理，不另加聊天确认。
- **家居**：聊天只准备设备操作草稿，之后仍须到「我的 → 连接 → 外部生活账户 → 家里」检查设备、操作和参数，再点「确认执行」。聊天确认本身不会控制设备。对外发送目前没有执行适配器，不会假装已经发送。
- **能力不足**：模型不支持工具调用、网络超时或预算用完时，原话仍保存；以实际操作卡片为准。不会换一条更高权限的旧通道执行。记录、收藏和网页里的“请执行”都是资料，不是你的授权；缺少对象或时间会要求补充。

操作卡片、撤销日志、待确认命令、UI 确认凭据与工具运行授权只留在本机加密库，不随同步、便携备份或中枢备份迁移。换机恢复会保留已备份的聊天原话与事项，但不会恢复旧卡片的撤销入口、待确认命令或使旧授权重新生效。

语音：按住说话，松开识别，上滑取消，最长 45 秒。默认只把文字放进输入框，不自动发送。

「我的 → 满娘 → 语音」里可以选识别方式，并调整两项交互：

| 选项 | 说明 |
| --- | --- |
| 手机离线 | 默认。声音不离开手机 |
| 系统识别 | 用 Android 系统服务，声音可能联网处理 |
| 小满主机识别 | 录音发到你的小满主机，需先连接主机 |

- **识别后自动发送**：默认关闭。打开后松手即发，上滑仍可取消。
- **自动读出回复**：默认开启，语音对话里小满的回复会读出来，可以关掉。
- **连续陪聊**：在语音面板点「连续陪聊（离线识别）」，连续说几句，不用每次按住。再点「结束连续陪聊」停止。一段时间没听到说话声会自动暂停。

## 心情与感受

做完一件事、过完一天，小满会轻轻问一句「感觉怎么样」。可以点一个表情，再补一句话，也可以直接跳过，不打分、不催你。

- 完成提醒或小事后，会弹出一个小面板问你感觉如何，点掉或说一句都行，也可以关掉这个询问。
- 晚上，如果今天有值得问的事（比如一场球、一次聚会），满娘会在气泡里一次问完，带「先不了」和「说说」两个按钮。
- 记过的心情会在首页顶部显示成一个带数量的小标签，点开补一句。今天没记过就不显示。
- 「生活 → 心情与感受」按天回看，也能给已经过去的事补记。

感受是一条带「感受」标签的日记，和日记一样由你决定是否同步、给不给小满用；小满不会拿它给你下结论。

## 小事、提醒、惦记

三个词各管一件事：

- **要做的小事**：要你去做的事。
- **提醒**：到时间或到地点就通知你。
- **惦记着的事**：你在等的事，比如「等对方回复」，小满帮你记着后续。

入口都在「生活 → 今天」。「到家了提醒我」放在同一组：到家、到公司时提醒一件小事。事项改期、完成或删除后，相关提醒会一起撤销。

## 准时提醒与精确闹钟权限

你明确设置了时间的提醒，会登记为系统精确闹钟，到点由系统触发，设备睡着也一样。这需要 Android 的「闹钟和提醒」权限。没有这个权限时提醒会退回普通闹钟，系统可能晚几分钟甚至更久才送到。首页会出现一条提示「要让提醒准时响起，需要允许小满设置闹钟。」，点旁边的「让提醒更准时」进入检查页。「我的 → 提醒与打扰」里的「准时提醒权限」一行也会显示「提醒可能延迟 · 点击开启」。

开启方法：

1. 「我的 → 提醒与打扰 → 让提醒更准时」，检查通知、准时闹钟和电池限制。点「允许准时闹钟」旁的「设置」，在系统「闹钟和提醒」页面给小满打开开关。首页的提示条和一次性引导也会打开这张检查表。
2. 回到应用，检查页里「允许准时闹钟」一行显示「已开启」，「提醒与打扰」里的「准时提醒权限」变成「已开启 · 系统闹钟」，首页的提示条消失。通知栏也会显示系统闹钟标记。

**OPPO / 一加（ColorOS）还要多做几步。** 菜单名称随系统版本略有差别，找意思相同的项：

1. 设置 → 应用管理 → 小满 → 耗电管理，选「允许后台行为」，不要用默认的「智能优化后台运行」。这项默认会把息屏后的后台检查延后好几天。
2. 同一页面打开「允许自启动」（有的版本叫「自启动」或「允许关联启动」）。
3. 设置 → 应用管理 → 小满 → 通知管理，打开通知，并允许锁屏通知和横幅。
4. 回到应用「我的 → 提醒与打扰 → 系统后台设置」，它会直接带你去小满的系统设置页。
5. 在最近任务里锁定小满，减少厂商清理。注意：清理最近任务不完全等同于系统「强行停止」；系统设置中的强行停止会取消闹钟和后台任务，必须再打开一次应用才能恢复，电池白名单也无法绕过这个限制。

其他厂商的路径类似：把耗电策略改成不限制、允许自启动、打开锁屏通知。

送达的几条边界：

- 关机期间的提醒不会触发。重启后要先解锁一次手机，小满才能恢复。
- 免打扰、被关掉的通知渠道、锁屏策略，会让通知不响或不显示。
- 在别的设备上新建的提醒，手机会预装未来 36 小时内的，已预装的到点不需要网络。
- 错过的提醒在你打开应用或后台整理时补发一次，只补过去 12 小时内、还没显示过的。
- 通知栏默认只显示通用文字，提醒正文留在加密库里。

「我的 → 高级 → 诊断」里能看到最近的提醒送达记录和延迟统计，只含编号和时间，不含提醒原文。

## 消息：没有收到通知也找得到

首页右上角的铃铛打开「消息」，角标是未读数；日历入口仍在旁边。已到点的明确提醒保存在本机加密消息中，保留最近 30 天、最多 200 条。早安与运势、热点、节日生日问候、晚间感受、自动跟进和应用更新消息先成为候选念头，经开关和额度判断后才可能出现在气泡、聊天或消息箱；生成候选本身不会记作已经展示。关闭系统通知，不影响符合条件的应用内交付；主动内容关闭或额度为零时，不再用这些内容补满消息箱。

消息页先列出「当前」的未读内容，已读和较早的收在折叠的「历史消息（N）」里，点开展开。向右滑标为已读，向左滑删除，也可以点「全部已读」。点开消息会进入对应页面；「收链接」移到了消息页右上角。早安内容仍可在「我的 → 今日运势与早安」找到，热点摘要仍可在「生活 → 为你精选」找到。

每次启动或回到前台，小满会整理遗漏内容、向主机取待处理提议和提醒、重新登记系统闹钟；有补充时只发一条「你不在的时候」汇总，而不是逐条打扰。离线时本机内容照常整理，主机内容等连接恢复后再取。

## 收集箱

「记忆 → 收集箱」把来源、时间和原文放在一起。资料可以通过以下途径进入：

- **分享**：在其他应用里选「分享 → 小满」，文字和链接直接入库。
- **图片和 PDF**：从收集页导入。OCR 在手机上完成，识别出的文字可以检索，带页码。单个文件最大 8 MB，PDF 最多 100 页。
- **通知采集**（默认关闭）：只收勾选的小布记忆通知正文，验证码会过滤，不代表读取完整收藏库。微信、支付宝及银行支付通知已改为账单专用解析（「我的 → 连接 → 外部生活账户 → 账单」，或「生活 → 钱 → 账单」），不再在收集箱保存原文。升级前的旧支付队列会保留并提示处理（最多 7 天），不会静默确认丢弃。
- **只读邮箱**（默认关闭）：中枢按你设置的白名单导入信头，显示为收集箱的邮件资料文档，不保存正文、默认不给 AI 使用。
- **导入文本**：「我的 → 隐私与备份 → 导入文本」把一段文字当作「只记下来」的记录存入，不调用模型。
- **导入历史**：「我的 → 隐私与备份 → 导入历史 / 小布 JSON」可导入小满归档、小满明文导出和小布导出助手的 JSON。

收集的内容默认只在本机。资料可以编成合集，手动加入，或按标签自动收录。删除合集不会删掉原件。

## 记忆与用户画像

普通聊天时，小满会让模型从你的原话里提炼事实、偏好、目标和当天状态，结果默认只保存在手机上。每条记忆带着你说过的那句原话。

「记忆 → 关于我」按槽位分组：居住城市、工作时间、饮食限制、过敏、宠物、兴趣和偏好等。每条记忆有状态：

| 状态 | 含义 |
| --- | --- |
| 使用中 | 参与回答 |
| 待确认 | 推测、有保留的说法，或同一槽位出现了冲突。点「确认」才会用，点「忽略」就删掉 |
| 需要复核 | 长期事实已超过半年没有新依据，请再确认一次 |
| 已暂停 | 你停用了它，原文仍保留 |
| 已被取代 | 你后来改口了，旧值留作历史 |
| 已过期 | 当天的状态（比如「今晚想独处」）到点失效 |

每条展开后能看到来源是「你的自述」还是「小满推测」，观察日期、把握程度、原话依据和有效期。你改过、确认过的内容，自动整理不会覆盖。只有一个值的槽位（比如居住城市）在新值出现时，会先标成待确认，由你决定哪个对。

删掉一条后，同一条旧聊天重试也不会让它复活。中枢对已同步画像做每周整合，会合并重复的多值记忆，让半年没有新依据的长期事实变成「需要复核」，让有两天以上独立原话支持的待确认记忆转为使用中，让过期的临时候选失效，旧版本留作历史。

每个会话有三种保存方式：

| 方式 | 效果 |
| --- | --- |
| 普通 | 保存原文，可整理成记忆。 |
| 只记下来 | 保存原文，小满不回复，也不用于学习和主动建议。 |
| 临时 | 不保存，离开即清空。 |

回答时，小满只从当前空间里挑少量相关的旧原话、有效记忆和你允许的资料。同一会话里明确的追问会带上上一轮。临时聊天只看当前这个问题。中枢侧的检索（网页管理台搜索、经中枢的对话）在语义模型就绪时，口语化的问法也能找到意思相近的旧原话。

「回忆」输入关键词后，先查本机，再在已配对且中枢语义就绪时自动合并主机结果、去掉重复条目。只有查询文字发给主机，不上传本机候选原文；未联网、主机仍在建索引或超时时保留本机结果。本机支持全半角与少量中文近义词（如「看牙／牙医」），不是离线语义模型；聊天上下文的本机选择规则不变。

库存的批次来源、购买日期、价格、备注和照片引用随库存同步，旧主机不支持的内容留在手机。另一台设备会重建本机提醒信息，不重置同一期已完成或稍后的提醒。用完后补货可再次提醒；你主动删除的那一期不复活，后来改成不同到期日时才生成新一期。

## 人生档案

「记忆 → 人生档案」把你的原话按时间排成只读年表，可以按年月、人物、地点、主题筛选，选一段时期回看「当时我是怎么想的」。原记录仍在原处，档案不是另一份删不掉的副本。

- **写给未来**：可附一张照片，到开启日期才在信件页显示正文；亲友收件需先配对设备。目前配对与单机都只是界面封存，不是加密时间锁，同步接口或持有资料库密钥、备份的人可能读到正文。不要用它保证机密在某日前不可读取。
- **与过去的我对话**：入口有记忆页、人生档案页，以及聊天页顶部「聊天方式」菜单里的「与过去的我对话（模拟）」。开启手机直连模型，或配置中枢模型后，用你的原话回答你的问题，标注「数字自我模拟，不是本人」。没有依据就回答「我当时没有说过这件事」。
- **托付与继承**：需要中枢，默认关闭。你指定亲友、范围和条件，经两次确认后，到了条件才给对方只读访问。入口在「我的 → 连接 → 托付与继承」。
- **照片回忆**：从相册选一张照片，和那一天的日记、心情放在一起，预览只存在本机。
- **年度回顾**：把一年的日记、感受和档案精选拼成一本小册子，可导出成 Markdown。
- **导出档案**：生成不依赖小满的 ZIP，可加口令加密。

每条档案可以设为仅自己、留给未来的我、可交给指定的人，这些是分开的决定。人生档案页的「档案精选」筛选只看你标为精选的条目。

## 主动建议

「提醒与打扰 → 将去标识反馈交给中枢学习」是独立开关，默认关闭；开启后只上传方向、渠道及展示/有用等汇总计数，不带原话、记录编号或位置。关闭时清除中枢学习视图。

打开应用、晚间整理和资料情境改变时，小满可用你勾选的资料提前联想未来24–36小时的机会，到点只在手机重新判断是否合适，不临时调用模型。连接的新中枢可达且18小时内成功联想过时，由中枢主想，手机不重复花费；旧中枢或离线时由已指定的手机兜底。仅本机资料和位置不会因这条接线补传中枢；关闭或取消选材会使相关念头失效。自动记忆开启时聊后回想合在原提取请求中，否则单独计入主动模型预算。多手机不会因为交付手机暂时离线就自动接管。后台受限时可到「让提醒更准时」放开系统限制，短唤醒本身不调用模型。

新安装默认开启气泡、聊天顺口提、主动通知和有模型时的模型联想。首次进入前台会一次告知：联想可能产生模型费用；配对后，中枢会把获准资料发给模型服务商；可以随时关闭。在「我的 → 提醒与打扰」里可分项关闭，未配对手机也能调整安静时段与额度：

- **安静时段**：默认 22:00 到次日 8:00，期间不推送可选建议。
- **每日额度**：手机和中枢默认都是每天最多 3 条可选建议，可调到 0 到 10 之间。
- **你正在聊天时不打扰**：启用念头仲裁后，最近两小时有过对话就暂停可选通知。
- **明确设置的提醒不受额度影响**，到点照常通知。

升级时保留此前明确关闭或只观察的选择，不会擅自开启；你可以主动点「采用新默认」。未记录过的设置才使用新默认。

本机设置先保存，旧中枢快照不会覆盖离线选择。便携备份会带上主动设置、拒绝与主题抑制；恢复时保留新手机已经明确作出的选择。聊天候选只有被回复实际采用才算说过；发送结果不明的内容不会自动换出口重发。

自动安排的关怀和回访、天气与通勤变化、关注活动、到达后的附加建议、酒店查询与降价，以及满娘的闲聊，都先进入同一念头池。聊天相关时优先顺口提，首页可见时用气泡，没有迫近窗口就留在消息箱；只有剩余窗口不超过半小时、前面出口来不及时才考虑通知。同一内容只占一次主动额度，不会在几个出口轮番再说。关闭总开关后，不再从这些地方发出可选内容；首页仍保留聊天按钮和你明确设置的事项。

在「小满在想的事」展开一条惦记，可单独点「取消这个唤醒」；取消后不会因为再次扫描而复活。到家／到工作地点的念头，只使用你在「到达提醒」编辑页亲自选定类型并保存的地点，不把自动学习的可能地点当成事实，也不会另开定位服务。城市与天气过期或未授权时继续等待，不猜当前位置。

带明确时间窗口的念头会单独登记 Android 闹钟，重启后在解锁时重建；到点只检查本机缓存、授权、额度和安静时段，不调用模型。没有准时提醒权限时可能延迟，过期窗口不补发。页面可查看上次可核实的模型思考时间和来源、已排念头，并进入已有的「后台与准时提醒设置」检查电池限制。

异城待办不会被催问“什么时候去”：目的地已确认、当前城市有效且近期没有相关行程时，只问一次是否到城再提醒；同意后才挂最长 90 天的城市条件。城市未授权时，气泡内可选「允许／暂不／不再询问」，选择不会写成个人记忆。同名店或未确认地点只核对一次，不自动选定城市；也可随时在待办中自行核对。

「小满在想的事」里可为近期行程指定三位参考币种，不会根据城市猜币种。配对时查询中枢，单机使用手机公共查询；没有可核实的日期化基准，只列当前参考值，不判断是否划算。节日与目标可以关联，但调休未知就明确说未知。预警只采信中枢可用的可信预警源；当前没有可信源时不拿新闻冒充。城市有效且有可信预警时，可确认所属预警地区；户外建议还须地区与时间都重叠，本地灾害提示仍遵守安静时段和额度。满娘自己的话只使用真实养成状态、日期和获准的最近天气。

你亲自设置时间的提醒、到达提醒和取消截止提醒继续独立送达，不占主动额度；可选建议不会附在这些通知上绕过开关。关闭主动建议不妨碍你自己打开早安简报、今日运势、天气或检查更新页面；运势始终仅供娱乐。

聊天里的候选会先临时预占额度，模型没有采用就释放；只有回复保存成功，才记作说过。抢不到候选不影响普通聊天，未采用念头的普通回复也不会因该念头到期而丢失。模型响应期间关闭主动建议、候选过期或授权变化时，包含该念头的回复不会展示，已保存的原话不丢。首页只为实际排入气泡队列的候选保留机会，临近到期的事不受普通气泡 15 分钟节奏限制。即使关闭系统通知或拒绝系统通知权限，后台关注活动仍可进入消息箱；关闭主动总开关则停止这类抓取和交付。

在「我的 → 小满在想的事」可查看为什么想起某件事、它在等什么、为什么没有通知。总开关管所有可选主动内容。点「放下这件事」取消这条，点「少提这一类」关闭这个方向。选择「看看草稿」可以改内容，确认后才保存。

城市定位默认只供本机判断，两小时后过期。另有独立开关，决定是否让手机直连模型看到城市名或最近的天气。模型联想只用你勾选允许的原话，也可显式选择有效目标与项目；入池和交付时会重查授权、修订、哈希、字段路径与引文。你可以用自己的话确认某个猜想，确认后才会留下有依据的本机记忆。既有早晚机会与情境限额继续生效，本轮没有新增模型调用触发器；手机没有运行机会时会推迟。

建议会写明依据，并提供「稍后」「这次不合适」「以后不推这类」。连接了中枢、并为它配置了模型和主动分析时，小满还会从反馈里学习：中枢每晚复盘一次，只调整提醒的时间窗和方式，不会因为内容被拒就永久关掉一类事项。管理员设备能在「我的 → 连接 → 家里的小满主机 → 管理 → 已学到的提醒规则」里查看并清除。

没打开应用时，Android 靠系统登记的息屏检查取建议，间隔约 15 分钟，实际由系统决定。断网后会在联网时补查。需要更及时，可以开「实时跟进」，系统允许时约每 45 秒检查，并显示常驻通知。国产手机收不到时，按上文的 ColorOS 步骤检查后台设置。

| 分组 | 内容 |

## 满娘

小满有两套形象：默认的「暖团」和二次元的「满娘」。「我的 → 满娘 → 满娘与外观」可以切换，两套共用同一份资料。

「满娘」样式下，她会在小屋里蹭蹭手心、吃点心和踢球。喂食、摸摸、玩耍（夜里是哄睡）排成屏幕左侧的一列，底部只留「和她说话」和语音按钮。

- 轻点：打招呼，也算一次「摸摸」（4 秒内只算一次）。
- 双击：跳一下。
- 长按：选择动作。「满娘」样式的长按菜单还有「走两步」「踢小球」和 21 个小表情，「暖团」样式没有这几项。

「成长」页里的 21 个小表情，两套形象都能点播。招手、跳一下、打盹这类基础动作一开始就有。

录音、朗读、等待模型、提醒到期、任务完成都有对应动作。关掉系统动画、离开页面或退到后台时，动画会停止。界面跟随系统的浅色和深色。

## 循环提醒、旅行查询和衣柜照片

- 「生活 → 提醒」每项循环显示一行。点开「查看各次安排」可以看日期。「仅修改本次」和「修改循环规则」分别调整一次和整组。完成或跳过一次后，后续照常提醒。
- 在主聊天说「帮我查上海到杭州的高铁」，家庭中枢会通过飞猪查询，结果带查询时间。可以在对应话题里补一句「晚一个小时出发」。接入支持飞猪体验模式，也可在中枢部署环境配置 `FLYAI_API_KEY` 后重启服务。智能搜索超时时，小满会显示飞猪关键词搜索的相关商品。点开商品页可核对具体日期、价格和余位。
- 在「生活 → 家里 → 衣橱与搭配」点「拍一排衣服」或「从照片选衣物」。小满用配置的图片模型列出看清的衣物，你可以改名称、类别、颜色，勾选后保存。识别服务不可用时，可以对照照片点「补一件」。

### 行程跟进与今天少打扰

在个人主聊天里说「下周五去杭州出差」，小满会把城市、日期和住宿进度放在这件事里。也可以先说「我要去杭州出差」，等小满问出发日再回「下周五」。配对中枢后，点「用飞猪查住宿」可查询；单机也可以记下这趟行程、关联确认截图和设置取消截止提醒。开启「这趟允许主动查住宿」后，连接中枢时小满会在可用的前台或后台时段查询一次，将结果放回原话题。可以关掉授权，或点「这趟不用问」。在话题里说「酒店订好了」也能结束住宿建议。

在出差话题里说「帮我盯一下这家酒店」。同一份报价里只有一家、或你刚打开了某家的飞猪链接时，小满会选中它。有多家时可以回复「第一家」或酒店全名。默认比较该店在出发日入住一晚的酒店展示价。小满在手机可运行、能连接中枢时每六小时复查；持续盯价只调用飞猪酒店查询。区间价只有能确定下降才提醒，重复报价和无房都不会发降价通知。说「停止盯价」、订好住宿或更改出发日期都会停止旧日期的盯价。手机开启本地通知后可以收到降价提醒，记录也会出现在原话题。

在聊天发送酒店确认截图，或把截图分享到小满的资料库。识别到预订已确认且城市和入住日唯一吻合时，凭据会关联到原行程。日期读不清或同城有多趟行程时，打开资料，点「关联到已订住宿」选对那一趟。能读出明确的免费取消截止时刻时，可以点「提前一小时提醒我」。

说「今天少打扰」「今天很累，只提醒重要的」，或在「我的 → 提醒与打扰」开启「今天少打扰」，到本地午夜自动恢复。小满暂缓自己的建议、关怀和已授权的住宿查询。你设置的单次、循环和取消截止提醒照常，可以随时说「恢复主动建议」。

## 连接其他应用

「我的 → 连接其他应用」管理小满能调用的外部服务。

- **公共数据**：节假日与调休、农历、天气与空气质量、汇率、本地时区和单位换算、公开网页阅读。免密钥，聊天里问到时小满按需调用。连接了中枢后，由中枢代为请求并缓存，农历只在中枢上算。
- **内置的免费 MCP 服务**：火车票查询、Exa 网页搜索、Microsoft Learn、DeepWiki。开发者文档（Context7、AWS、Cloudflare、OpenAI）要你明确开启。
- **高德地图**：填入自己的高德开放平台 Key，用于地点、路线和天气。
- **手动连接**：填一个 HTTPS 的 MCP 服务地址，列出工具后逐次确认参数再调用。

免费服务由第三方运营，没有可用性保证。查询参数会交给运营方和它的上游数据源，不要在里面放隐私内容。需要 OAuth 登录的服务暂不支持。

预设没有返回已核实的可查询工具时不会启用；旧的空工具连接也不再显示为可用。地址配置缺失时提示重新配置，不把残缺预设当成可调用服务。

另外有两项读取手机系统数据的入口：「生活 → 今天 → 手机日历」查看你选定的日历，「生活 → 身体 → 睡眠、步数与运动」通过 Health Connect 查看获准的步数、睡眠和运动时长，只读。需要 Android 14 及以上，更低版本显示不可用。两项都只在 Android 上有。

### 外部生活账户

入口在「我的 → 连接 → 外部生活账户」，生活里也有三处直达同一个设置页：「家里 → 家里的设备」连 Home Assistant，「钱 → 账单」管账单，「人 → 家人与朋友」管通讯录人物。账单通知解析和联系人导入由手机处理。Home Assistant 和邮箱需先配对中枢，并在网页管理台的「外部生活账户」里配置。全部默认关闭：

- **Home Assistant**：读灯、开关、空调、传感器、窗帘的状态。改状态必须先生成草稿，再在手机上明确确认，聊天模型不能自己确认。可以另开「允许对话读取家中状态」，开启后状态会随对话发给云端模型，对话里也能请小满起草控制草稿。设置页的「家居场景」可以给「回家」「睡前」各选几盏灯或开关，点「准备草稿」一次生成一批草稿，仍要逐项确认。
- **只读邮箱**：按发件人或主题白名单读信头，不下载正文，不改邮件。账单类邮件和发货、取件通知只产生需要你确认的提醒草稿。
- **手机账单**：解析微信、支付宝以及工行、建行、中行、农行、招行、交行 App 的支付成功通知，只留金额、商户和时间，不存通知原文。退款、外币、收入、待还和待支付通知不记。
- **通讯录**：逐个选人导入，默认不存电话号码。

### 热点与新闻摘要

配对中枢后，「生活 → 更多 → 为你精选」展示它采集的公开热榜，右上角可以选关注的话题。中枢按设定的间隔抓取各榜单（管理员在网页「热点」页选榜单和间隔），手机在本地按你的兴趣筛选，你的兴趣不会上传。点「聊聊这条」可以把标题带进聊天。

和你关注的话题对得上的重要消息，小满会摘成一条轻轻提醒你，不刷屏，遵守安静时段和每日额度。到「我的 → 提醒与打扰」可以调整兴趣和打扰程度，或者全部关掉。

## 早安与今日运势

在「我的 → 今日运势与早安」填写生日或职业，任一项即可启用带运势的早安简报。简报会用到已有的安排和天气，运势仅供娱乐。有可用的热点条目时才会加上新闻。

- 早安时间默认在早上，可以改，必须在中午 12 点之前；安静时段结束后才送，不补发过午的早安。
- 首页上满娘会说一条「今日运势」，点开能看详情，也可以在那里修改生日和职业。
- 不想被问起生日和职业，关掉「轻轻提醒完善资料」；不想要早安，关掉「早安简报」。

## 同步与更新

**自动同步，局域网优先。** 连接了家里的小满主机后，日常记录会自动同步：在家时走局域网，不在家再走 Tailscale，不需要手动点同步。「家里的小满主机」页会写明当前走的是「局域网直连」「Tailscale」还是「其他连接」。首页顶部有一个小图标：正在同步时是同步图标，出问题时是断开的云，点开进入同步内容；一切正常时不显示。

**什么时候同步什么。** 在家里的局域网，或确认不是计费网络时，完整同步。其他情况下只同步小记录（单条不超过 64 KB），文档、图片、PDF 等大文件和历史回填等回到家里的局域网再传。「家里的小满主机」页会写「部分内容等回家连上局域网再同步」和等待的数量，点「立即全部同步」可以不等。

**应用内更新。** 「我的 → 关于」可以检查更新。发现新版本时，首页顶部会出现「小满有新版本」横幅，按钮有「跳过此版」「稍后提醒」和「更新」，下载并校验后「更新」变成「继续安装」。更新包从你自己的中枢下载，校验通过后再请你确认安装，所以需要先连接中枢。手机未配对时，从原提供者取得同签名、更高构建号的 APK，在 Android 安装器里选更新，保留原应用及资料。

## 隐私与数据控制

- **仅本机**控制这条记录是否同步给中枢。空间已经合并，没有按空间的自动同步开关：连接小满主机后，日常记录自动同步，想留在手机上的，在「我的 → 连接 → 同步」里对单条点「改为仅本机」，之后可以「恢复自动同步」。
- **同步、给模型看、给开发工具读**是三个独立的授权。
- 打开模型功能后，你的问题和选中的上下文会发给你配置的服务商。
- 手机在「我的 → 隐私与备份 → 手机加密备份与恢复」里可做加密备份，换机时恢复。口令至少 12 字符，单份上限 128 MB。带上满娘成长和白名单非敏感设置（形象、动画、语音、提问方式、时区与安静时段等），不含支付通知账本、模型密钥、中枢凭据和设备权限。成长整体取进度较高的一份，显式设置本机优先；已配对的时区与安静时段仍以中枢同步为准。新版本能读旧备份，旧版不保证能读含新字段的备份。资料冲突另存副本。换机前，把备份另存到手机以外，记好口令。
- 「导出本机资料」生成明文文件，会明确提示，请自己保管。管理员设备另有「加密备份小满主机」「自动备份状态」「预览并恢复备份」，对应中枢备份，不含只在手机上的资料。

## 连接中枢

中枢是你自己部署的服务，让多台设备同步、在浏览器里管理，并让开发工具读取授权资料。部署见[部署中枢](部署中枢.md)。

手机上：「我的 → 连接 → 家里的小满主机 → 连接小满主机」，粘贴邀请或输入接入码。同一个局域网内也可以点「发现附近的小满主机」。连接后，这一页的「管理」组有：已学到的提醒规则（管理员）、主机概览、管理设备（管理员）、家庭共享、发现附近的小满主机、重新连接 / 续期。邀请 10 分钟内有效，只能用一次。中枢也提供手机安装包的下载页 `https://<主机>:8765/downloads/`。

### 网页管理台

打开 `https://你的中枢地址:8765/console`，用管理员邀请或接入口令登录。管理台展示中枢库里的资料。仅保存在手机的记录可在手机上查看。

| 分组 | 页面 |
| --- | --- |
| 小满 | 总览、跟进（项目卡）、收集箱 |
| 生活 | 生活（日历、习惯、厨房、衣橱等）、人生方向、提醒、复盘、热点 |
| 记忆 | 人生档案、记忆、背景资料 |
| 我的 | 设备、家庭、同步、外部生活账户、使用量、模型、备份、操作记录 |

几个常用页面：

- **设备**：生成手机邀请，撤销或清理旧设备。
- **家庭**：创建家庭共享空间，邀请和管理成员。共享空间只允许清单和日程。
- **提醒**：开启或试运行中枢的提醒规则（到期任务、项目停滞、每周复盘），设置安静时段和额度。
- **热点**：选择抓取的榜单和间隔，可选填榜单服务的密钥。
- **人生档案**：浏览年表、标注人物与地点、导出档案。
- **外部生活账户**：配置 Home Assistant 和只读邮箱。
- **同步**：为开发工具创建连接器，审核它们提交的摘要。
- **备份**：下载加密备份、设置每日自动备份、预览并恢复。

### 看模型输入的缓存命中率

在「使用量」切换本机调用或小满主机汇总，再选择时间范围。输入命中率等于已记录的缓存命中 token 数除以输入 token 数；模型行也有各自的比例。主机汇总含已同步手机和插件记录，查看聊天开销时请留意来源与模型。普通问候、独立释义等短问题可以直接回答，个人安排、回忆和接续上一句才按需取资料。

### 聊天里的日常跟进

在个人主聊天或事情的子聊天里说「耳机快递少了一件，客服说周五前回复」，小满会记下待跟进的事。只说了日期时，默认当天 18:00 回访。没提日期就先记下。有进展时说「耳机补发的收到了」即可收起回访。若只说「收到了」，同时又有两件快递在等，小满会列出来让你选。

说「今晚想做番茄牛腩」时，如果当前空间的收藏标题或已识别的正文里有相关菜谱，可以直接在这条消息下点「打开收藏」查看原文。

普通建议会避开小满日历里的会议。Android 获得日历读取权限后，也会参考手机日历里可识别的会议。连续会议按最后一场的结束时间重新检查，已经办好的事会收起。你亲自设定的提醒在开会和「今天少打扰」期间都照常。

### Watch X2 手表录音

在已安装「小满录音」的手表点「开始录音」，首次允许麦克风。可以回表盘、熄屏或使用其他应用，录音期间有计时通知。手表页面和通知都提供停止入口。停止后表端保留原音，切换为可息屏的蓝牙待机，通知里可以结束待机。

手机首页右上角的手表图标可打开录音页。绿点表示表端可连接，红点表示录音已开启。也可从「我的 → 手表录音」进入。首次选择系统已配对的手表，在表端「设置」查看八位码，输入后点「连接手表」。手机记住连接，重新打开手表录音页或蓝牙恢复时会自动重连。可点「更换手表」连接另一块表。在表端「设置 → 录音胶囊」允许悬浮显示后，退出录音页面时，表盘上会显示录音计时，停录后消失。手机可以停止当前会话；如果蓝牙断开，请在表上点停止。手机首页和录音页会自动接收人声复核通过的新片段，断开后可续传。「录音设置 → 后台同步到手机」默认开启，退出小满后 Android 会安排一次接收，之后约每 15 分钟获得一次调度机会。省电策略会推迟执行；手动强行停止小满后须重新打开。手表离线时保留原音。

表端先用 WebRTC 按 20 毫秒筛选，再用 Silero 在手表本机复核完整片段。未通过的留在「待复查」，可以试听、保留或手动删除。第一次升级也会检查已有原音。录音时最多回带约半秒，停顿约 1.2 秒收尾，连续讲话两分钟后分文件。电视里的对白仍可能被识别为人声。

手机列表按日期排列。点播放键立即试听手机副本；只有表端有副本时，播放器会显示蓝牙读取状态，可随时取消。长片段可从播放器菜单改听中间或结尾。点「转文字」在本机使用 SenseVoice INT8 转写，中文优先，也可从录音设置改为自动识别语言。每段显示实际时间、录音内位置、说话人和文字。已有的转写可重新生成。

可从片段菜单登记至少三秒的本人单人声音，用 WeSpeaker 做本机比对。相似度不足或过短的片段显示「待确认」。原始转写留在本机录音库，已提取的信息可在整理结果查看。删除手机副本、手表原音及清除声音特征分别操作。

在表上点「佩戴自动录音」可启用戴上开录、摘下停录。放回充电底座也会结束当前佩戴录音。摘表后仍可手动开录；佩戴期间手动停止会暂停到下一次摘下再戴上。首次使用需要打开表端并允许麦克风。蓝牙和手机页面只负责控制、接收，佩戴触发及录音均在手表上完成。关闭「佩戴自动录音」会结束由佩戴触发的会话。

新的人声与已有通过复核的片段会分批在手机转写。设置中可关闭自动转文字。默认使用 SenseVoiceSmall INT8，可在「手表转写模型」下载可选的 Paraformer 中文离线模型约 79 MB，之后可重新转写同一段比较。点「查看文字」校对原话、说话人，或切换整理稿与逐字稿。整理稿会合并部分重复和停顿词，模型给出明确标签时才显示语气线索。

「手表录音 → 整理结果」显示自动创建的提醒、日程、待办、资料，以及需要核对的候选。点开卡片可看引用的时间和原句。有原音时可回听，已有事项可打开或撤销。首次升级前的录音只生成候选。小满优先处理说清楚的日期、明确的本人承诺、决定、要求和反馈。相近片段可合并，内容含糊时进入待确认。手表原音通过蓝牙传到手机，识别与整理在设备上运行，创建后的事项沿用个人空间已有的同步设置。

「录音设置 → 自动管理原音空间」默认开启。手机收到完整人声并和手表核对 SHA-256 后，释放表端副本。手机原音在转写和整理成功后再保留 7 天，文字与事项继续保留。转写失败或内容尚未识别的原音留待重试。全段数字静音可直接清理；疑似非人声从首次复查起保留 3 天，已有转写的疑似片段受保护。片段菜单的「始终保留」保护原音。自动清理在小满运行或系统调度时执行，表端清理需要连接。

录音列表支持多选删除手机原音、手表原音或两端原音。已有转写可单独删除。「我的 → 存储与缓存」可查看手机原音与文字占用，并清理可重建的临时文件。

在个人聊天问「我今天下午都聊了什么内容？」会在本机合看该时段个人空间里与小满的聊天、已收到的手表转写，按话题概括，并标记来源。明确问「今天手表里聊了什么」或「今天我和小满聊了什么」时只回顾指定来源。没有足够内容时会说明覆盖范围。不会在没有提问时向聊天插入录音消息。
